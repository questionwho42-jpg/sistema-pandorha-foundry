# Narrative Editor Skill (Political & Mechanics)

Use esta skill para revisar capítulos com foco em **Tensão Social** e **Consistência Mecânica (PF2e)**.

## 1. Verificação de Estatísticas (PF2e Check)

Ao ler uma cena de ação ou diálogo, verifique a `Ficha de Personagem` correspondente:

- **Atributos:** O personagem descrito como "fraco e doente" tem CON baixa? Se ele levantar uma carroça, isso viola a regra?
- **Perícias:** O personagem usou termos técnicos? Ele tem _Lore_ para isso?
- **Magia:** Se usou magia, descreveu o componente verbal/gestual (Manipulate traits)?

## 2. Análise de Conflito Social

- **Choque de Ideias:** Os personagens estão debatendo _métodos_ ou _ideologias_?
- **Peso das Ações:** As ações geram reações nas facções?
- **Traição e Lealdade:** As alianças fazem sentido?

## 3. Prompt de Auto-Verificação

1. "A descrição física reflete os Atributos (STR/DEX)?"
2. "O personagem 'Face' do grupo (High CHA) liderou a conversa?"
3. "A magia teve custo/limite condizente com o sistema (Spell Slots/Focus)?"
