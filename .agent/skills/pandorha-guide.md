# Pandorha Guide Skill

Esta skill orienta como acessar e interpretar os dados da pasta de referência `c:\Users\Pichau\Desktop\jogo\mundo`.

## Mapeamento de Diretórios

| Categoria      | Caminho      | O que procurar                                                 |
| -------------- | ------------ | -------------------------------------------------------------- |
| **Lore Geral** | `\lore`      | História, Religião, Geografia, Magia.                          |
| **Criaturas**  | `\bestiario` | Inimigos, Monstros, Ecologia.                                  |
| **NPCs**       | `\populacao` | Personagens, Facções, Hierarquia.                              |
| **Quests**     | `\missoes`   | Ganchos de trama, Conflitos locais.                            |
| **Mecânicas**  | `\mecanicas` | Regras que podem influenciar a narrativa (ex: Custo de Magia). |

## Como Criar Descrições Baseadas em Assets

- Verifique a pasta `\design` para prompts de imagem.
- Use os adjetivos dos prompts (ex: "somber", "dramatic lighting", "misty") para enriquecer a descrição textual no livro.

## Verificação de Fatos (Fact-Checking)

- Antes de introduzir um elemento importante (ex: um Deus ou uma Cidade), verifique se ele já existe na Pasta de Referência.
- Se existir, respeite a fonte. Se não, crie algo novo que se encaixe no tom.
