# Workflow: Extrair Lore e Converter para Narrativa

1.  **Ler o Arquivo Original** com `view_file`.
    - Identifique: Nome, Papel, Personalidade, Conflitos e **Estatísticas (PF2e)**.

2.  **Criar/Atualizar Arquivo na Bíblia** (`o mundo de pandorha - livro/...`).
    - Use o template abaixo.

3.  **Adaptação de Estatísticas (NOVO)**
    - Não copie os números crus apenas. Adicione uma seção "Ficha Narrativa".
    - Converta Atributos altos (+4) em descritores (Fortalecido, Genial, Carismático).
    - Liste Perícias Chave (Skills) que definem como o personagem resolve problemas.
    - Liste Talentos (Feats) como "Habilidades Especiais" ou "Treinamento".

## Template de Perfil

```markdown
# [Nome]

> **Origem:** [Caminho do Arquivo]
> **Classe/Nível:** [Ex: Ladino 3] | **Background:** [Ex: Nobre Caído]

## Descrição e Atributos

- **Físico:** [Descrição visual ligada a STR/DEX/CON]
- **Mente:** [Descrição intelectual ligada a INT/WIS/CHA]
- **Perícias Chave:** [Ex: Diplomacia (Mestre), Society (Treinado)]

## Personalidade e Ideologia

...

## Ficha Técnica (PF2e Remaster)

- **Atributos:** STR +X, DEX +X, CON +X, INT +X, WIS +X, CHA +X
- **Saves:** Fort +X, Ref +X, Will +X
- **Feats/Habilidades:** [Nome do Feat] (Descrição curta do efeito narrativo).
```
