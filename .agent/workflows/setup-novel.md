# Workflow: Setup Novel Project

Este workflow cria a estrutura de diretórios padrão para a escrita do romance.

1. **Criar Diretórios Principais**
   Executar o seguinte comando para criar a hierarquia de pastas:

   ```powershell
   mkdir "00_Planejamento"; mkdir "00_Planejamento\Bible"; mkdir "01_Personagens"; mkdir "01_Personagens\Protagonistas"; mkdir "01_Personagens\Secundarios"; mkdir "02_Mundo"; mkdir "03_Manuscrito"; mkdir "04_Arquivo"
   ```

2. **Criar Arquivos de Controle**
   - Criar `00_Planejamento\Sinopse.md` (Template em branco).
   - Criar `00_Planejamento\Timeline_Livro.md`.

3. **Copiar Referências Cruciais**
   - Ler a `timeline_eventos.md` da pasta de referência e criar um resumo relevante em `02_Mundo\Contexto_Historico.md`.

4. **Confirmação**
   - Listar a estrutura criada para garantir que tudo está correto.
