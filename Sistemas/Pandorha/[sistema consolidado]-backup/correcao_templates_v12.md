# Ecossistema de Templates Concluído - v12 (Compêndio Total)

## O que há de novo?
Agora que a ficha do ator (personagem) está perfeita, expandi o sistema para incluir todos os tipos de itens necessários para a progressão e criação em Pandorha.

### 1. Novos Templates de Item
- **Ancestralidade**: Agora você pode criar itens como "Humano", "Elfo", etc., com campos para **Capacidade Primordial** e os **3 Traços Ancestrais**.
- **Classe**: Para "Vanguarda", "Tecelão", etc., com espaço para a **Habilidade Passiva** e os **2 Talentos de Classe**.
- **Antecedente**: Para origens como "Soldado", "Erudito", com sua **Habilidade de Origem** e **Talento de Antecedente**.

### 2. Integração Drag-and-Drop
- A aba **HABILIDADES** foi configurada para aceitar todos esses novos tipos de item. Você pode simplesmente arrastar uma Ancestralidade ou Classe da barra lateral para a ficha do seu personagem.

### 3. Design Coesivo
- Todos os itens seguem o mesmo padrão visual (Decorator) da ficha principal. Bordas douradas, fundo escuro e tipografia épica garantem uma imersão total.
