# 🏛️ Battlemap: Câmara Profunda (O Selo)

### Cena 3-5: O Combate Final e Revelação (Capítulo 2)

Mapa tático épico (16:9) estritamente retangular e sem grid.

## 📥 Importação

1. Copie para `Data/worlds/seu-mundo/scenes/karathon-camara/`
2. Importe o `scene.json` no Foundry.

## 🎲 Mecânicas de Clímax

- **Válvulas de Vapor:** Use as notas nas paredes para permitir que os jogadores usem o cenário a seu favor.
- **O Dilema de Dente-de-Ouro:** Quando ele oferecer o acordo (Cena 4), a posição dos renegados no mapa determinará se eles ajudarão os PCs ou hesitarão.
- **Revelação de Garth:** O selo no chão é o ponto de foco após a luta.
