# 🏛️ Battlemap: Pátio Exterior de Karathon

### Cena 1: O Acordo com Veros (Capítulo 2)

Mapa tático (3:2) sem grid na imagem, representando a entrada da fortaleza.

## 📥 Importação

1. Copie para `Data/worlds/seu-mundo/scenes/karathon-patio/`
2. Importe o `scene.json` no Foundry.

## 🎲 Notas Narrativas

- **Stand-off:** O centro do acampamento é onde ocorre o dilema com Veros.
- **Entrada:** A entrada ao norte leva para as profundezas (Salões Internos).
- **Legião:** Salve esta cena para o desfecho do capítulo (Chegada de Harken).
