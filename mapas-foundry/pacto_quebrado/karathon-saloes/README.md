# 🏛️ Battlemap: Salões Internos de Karathon

### Cena 2: As Profundidades (Capítulo 2)

Mapa tático (16:9) premium com foco em exploração e puzzles.

## 📥 Importação

1. Copie para `Data/worlds/seu-mundo/scenes/karathon-saloes/`
2. Importe o `scene.json` no Foundry.

## 🧩 Mecânicas de Puzzle (Notes)

- **Areia Magnética:** Localizada nas transições de nível. Afeta principalmente guerreiros de armadura pesada.
- **Porta Rúnica:** Descarrega 2d6 PV em caso de falha. Use o Lore para recompensar jogadores Elfos.
- **Bigorna de Torsten:** Parede falsa configurada com nota de detecção de anomalia.
