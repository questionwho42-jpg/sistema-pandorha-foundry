# 📁 Estrutura de Pastas - Cenário de RPG

Esta estrutura organiza todos os elementos de um cenário de RPG seguindo os 5 pilares do workflow `/criar-cenario-rpg`.

---

## Pastas Principais

```
rpg-cenario/
├── 01_Ambiente/       → Descrições de terreno, clima, mapas conceituais
├── 02_Conflito/       → Ameaças, facções, linha do tempo
├── 03_Sociedade/      → Governo, economia, tensões sociais
├── 04_Fantasia/       → Magia, criaturas, artefatos
├── 05_Narrativa/      → Roteiros, arcos, ganchos de aventura
├── 06_NPCs/           → Fichas e descrições de personagens
├── 07_Locais/         → Dungeons, cidades, pontos de interesse
├── 08_Encontros/      → Combates, puzzles, eventos
├── 09_Mapas/          → Mapas de mundo, dungeons, táticos
└── 10_Recursos/       → Handouts, músicas, tokens, arte
```

---

## Uso Sugerido

| Pasta            | Conteúdo                                                  |
| ---------------- | --------------------------------------------------------- |
| **01_Ambiente**  | Descrições sensoriais, clima, biomas, fenômenos naturais  |
| **02_Conflito**  | Perfil do antagonista, motivações das facções, cronograma |
| **03_Sociedade** | Leis, moeda, hierarquias, festivais, costumes             |
| **04_Fantasia**  | Bestiário customizado, escolas de magia, relíquias        |
| **05_Narrativa** | Beat sheets, roteiros de sessão, árvores de decisão       |
| **06_NPCs**      | Fichas estatísticas, backstories, vozes e maneirismos     |
| **07_Locais**    | Descrições room-by-room, segredos, tesouros               |
| **08_Encontros** | Estatísticas de monstros, táticas, recompensas            |
| **09_Mapas**     | Imagens de mapas, links para ferramentas online           |
| **10_Recursos**  | PDFs para jogadores, playlists, imagens de referência     |

---

## Arquivo Principal

O arquivo `_TEMPLATE_CENARIO.md` na raiz serve como documento central que resume todo o cenário e aponta para os detalhes em cada pasta.
